# Swarm sprite art (placeholders)

`games/swarm/src/sprites.hires.png` is generated by `make_sprites.py`; replace it with real art
without code changes as long as the shape order below and `check_sprites.py` hold. make converts it to
`build/swarm/sprites.hires.bin` (`.col`, `.inc`: `SPRITES_HIRES_COUNT = 13`). The sheet is one row of
13 cells of 24x21 (312x21 px). With the data at `$3000`, **pointer = `$C0` + index**.

| Index | Pointer | Shape | PNG colour (game colour comes from `colour_table`) |
|---|---|---|---|
| 0 | `$C0` | player | cyan (3) |
| 1 | `$C1` | player shot | cyan (3) |
| 2 | `$C2` | enemy shot | light red (10) |
| 3, 4 | `$C3`, `$C4` | enemy A (row 0), frames 1, 2 | purple (4) |
| 5, 6 | `$C5`, `$C6` | enemy B (row 1), frames 1, 2 | yellow (7) |
| 7, 8 | `$C7`, `$C8` | enemy C (row 2), frames 1, 2 | light green (13) |
| 9-12 | `$C9-$CC` | explosion, 4 shapes in order (small to sparks) | orange (8); the player's is the same shapes in white at run time |

The order is defined here (the design lists the 13 shapes but not their order).

```
uv run --package png2sprites python games/swarm/art/make_sprites.py [--preview]   # regenerate
uv run --package png2sprites python games/swarm/art/check_sprites.py [SHEET.png]  # check any sheet
uv run --package png2sprites pytest games/swarm/art -q
```
